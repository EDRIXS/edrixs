Examples

There are two ways to learn EDRIXS from worked calculations. Start with the pedagogical series to build up the underlying concepts and API one step at a time, or go directly to the NiO examples for complete XAS and RIXS workflows.

Pedagogical series

The pedagogical examples progress from exact diagonalization, crystal fields, and Coulomb interactions to atomic and Anderson impurity models. Each page includes the executable Python source and its generated figures.

NiO XAS and RIXS

The following examples use the backend-independent model and solver APIs for two descriptions of NiO:

  • NiO crystal-field \(L_{2,3}\) XAS & RIXS
  • NiO Anderson impurity model XAS and RIXS

The crystal-field calculation treats an ionic Ni \(3d^8\) site. The Anderson impurity calculation adds ligand orbitals and charge-transfer configurations through model_siam().
