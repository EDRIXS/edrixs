Release History

This page summarizes the user-visible changes in each tagged release. See the GitHub releases page for the complete release notes and downloadable artifacts.

v0.1.3 (2026-09-08)

  • Updated the build system to support installation on Apple silicon. This release does not change the physics functionality.

  • Revised the charge-transfer examples and documentation and made minor example-maintenance improvements.

Release notes | Changes since v0.1.2

v0.1.2 (2026-05-06)

  • Fixed several small issues in the solvers, examples, and documentation, including a missing spinor and outdated pkg_resources usage.

  • Improved wheel generation, supported Python versions, development-container setup, installation guidance, and documentation publishing.

  • Added and clarified examples for scattering geometry, NiO, and execution-time estimates.

Release notes | Changes since v0.1.1

v0.1.1 (2024-06-05)

  • Fixed the end_indx handling in the Fortran expectation-value driver and corrected macOS compilation.

  • Updated Docker packaging, installation documentation, and the publication list.

Release notes | Changes since v0.1.0

v0.1.0 (2023-10-13)

  • Added a CMake-based build and improved macOS support.

  • Added examples covering Hund’s coupling and charge-transfer excitons, and refreshed the existing examples and Binder setup.

  • Expanded the documentation and publication list.

Release notes | Changes since v0.0.8

v0.0.8 (2022-10-28)

  • Fixed polarization normalization in the Python XAS solver.

  • Added and revised RIXS, Hubbard-model, crystal-field, and transition examples, along with substantial documentation and continuous-integration updates.

Release notes | Changes since v0.0.7

v0.0.7 (2020-09-07)

  • Improved the examples, documentation, and installation instructions.

  • Added the missing Cu d10_2p5 Slater parameters and fixed several small issues.

Changes since v0.0.6

v0.0.6 (2020-07-08)

  • Added three gallery examples, including a charge-transfer calculation.

  • Added utilities that derive impurity and bath energy levels from the charge-transfer energy and U, and fixed several bugs.

Release notes | Changes since v0.0.5

v0.0.5 (2020-06-03)

  • Updated the documentation and examples, including expectation-value and Python-tips material.

Release notes | Changes since v0.0.4

v0.0.4 (2019-07-01)

  • Corrected the source distribution and extension-linker configuration for packaging, including Conda packaging.

Changes since v0.0.3

v0.0.3 (2019-06-28)

  • Included requirements.txt in the source distribution.

Changes since v0.0.2

v0.0.2 (2019-06-27)

  • Added simpler APIs for angular-momentum and many-body operators.

  • Corrected isotropic XAS calculations and improved Docker/Jupyter support.

Changes since v0.0.1

v0.0.1 (2019-05-15)

  • Initial tagged release of EDRIXS.
